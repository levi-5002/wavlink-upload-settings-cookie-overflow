# WAVLINK `upload_settings.cgi` Cookie stack overflow

Public advisory for a stack overflow observed in the `upload_settings.cgi` CGI of three tested WAVLINK firmware packages.

- **Advisory:** [ADVISORY.md](ADVISORY.md)
- **Evidence:** [isolated reproduction](evidence/upload_settings_repro.json) · [GDB crash excerpt](evidence/upload_settings_gdb.txt) · [2026-11-11 retest](evidence/upload_settings_retest_2026-11-11.json)
- **CVE status:** No CVE ID has been assigned to this finding as of publication on 2026-11-11.

This repository documents one finding across the tested products. The relationship to previously published Cookie overflow CVEs requires CNA review.
